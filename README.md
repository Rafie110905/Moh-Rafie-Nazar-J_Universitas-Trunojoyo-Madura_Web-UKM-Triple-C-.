## 📀 Tentang Proyek

Website resmi **UKM Creative Computer Club (Triple-C)** — dibangun dengan estetika
**retro desktop OS** ala Windows 95/98: boot animation, jendela `.exe` warna-warni,
dan efek scanline CRT yang bikin nostalgia sekaligus beda dari situs kampus kebanyakan.

> Bukan cuma company profile biasa — situs ini juga jadi *pusat komando* untuk event
> tahunan **Trunojoyo Creative Competition (TCC)**, lengkap dengan chatbot AI,
> panel admin, dan generator guidebook otomatis.

---

## ✨ Fitur Unggulan

| | Fitur | Deskripsi |
|---|---|---|
| 🤖 | **TCC Assistant** | Chatbot AI (Google Gemini) — jawab pertanyaan peserta lomba real-time |
| 📊 | **Admin Panel** | Kelola pesan masuk dari pengunjung, tanpa perlu database |
| 📄 | **Auto Guidebook** | PDF panduan lomba ter-generate otomatis per kategori |
| 🎨 | **Logo Animasi** | Icon animasi custom SVG untuk tiap cabang lomba |
| 🎬 | **Video Profil** | Looping showcase UKM di halaman beranda |
| 📢 | **Broadcast System** | Pengumuman pop-up yang bisa diatur tanpa sentuh kode |

---

## 🧰 Tech Stack

```
Backend    : PHP Native (no framework)
Frontend   : HTML5 · CSS3 · Vanilla JS
AI Engine  : Google Gemini API
Styling    : Custom "Retro OS" Design System
```

## 📁 Struktur Singkat

```

├── 🔐 admin.php              → Panel admin (dilindungi password)

├── 📦 includes/              → Komponen & konfigurasi
└── 🎨 assets/                → CSS, JS, gambar, video, dokumen
```
